## 🚀 서비스 구성

### 1. AI 영업지원 챗봇 (카카오톡 채널)
> **"거래처의 매출·재고·채권 현황을 카톡으로 즉시 조회"**

- 사번(로그인) 기반 개인화 조회
- 담당 거래처 매출 현황, 미수채권, 미출고 및 고객마스터
- 자연어 질문 → 데이터 응답

### 2. 세일즈 액션 플랫폼 (웹 포털)
> **"범용상품 판매 비중이 낮은 가맹점을 찾아 DM 발송까지 원스톱"**

- 브랜드별 가맹점 범용상품 구성비 분포 분석
- 타 가맹점 대비 미판매 상품 AI 추천
- 판가 설정 + DM 발송 실행
- 발송 후 실적(매출·GP) 추적

**최초 1회 등록 방법 (순서대로)**

1. 휴대폰 카메라로 **QR 코드 촬영** → 카카오톡 열림
2. **친구추가** 클릭 → **챗봇 대화 시작**
3. 대화창에 **사번 입력** → 시스템이 안내하는 **등록 절차**에 따라 진행
4. 최초 1회 등록 완료 후 이후부터 **대화 바로 시작**

> ⚠️ 커다 톡 연동이 안 되는 경우 카카오톡 앱 버전을 최신으로 업데이트 후 재시도해주세요.

## 👥 권한 구조

| 구분 | 조회 범위 | 해당자 |
|------|-----------|--------|
| **일반 영업사원** | 본인 담당 거래처만 | 전체 영업사원 |
| **팀장/지점장** | 담당 팀·지점 전체 | 외식1팀·2팀·3팀·영남지점 팀장 |
| **신규개발파트** | 외식식재사업부 전체(챗봇) (읽기 전용) | 신규개발파트 소속 |

- 본 서비스는 **Databricks 기반 실데이터**를 활용합니다. 조회 결과는 SAP 기준 데이터와 동일합니다.
