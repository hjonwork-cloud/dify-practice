**매출 분석 → 액션 제안 → DM 발송 → 실적 추적**까지 하나의 흐름으로 지원합니다.

## 🚀 서비스 구성

### 1. AI 영업지원 챗봇 (카카오톡 채널)
> **"거래처의 매출·재고·채권 현황을 카톡으로 즉시 조회"**

- 사번(로그인) 기반 개인화 조회
- 담당 거래처 매출 현황, 미수채권, 재고 현황 등
- 자연어 질문 → 데이터 응답

### 2. 세일즈 액션 플랫폼 (웹 포털)
> **"범용상품 판매 비중이 낮은 가맹점을 찾아 DM 발송까지 원스톱"**

- 브랜드별 가맹점 범용상품 구성비 분포 분석
- 타 가맹점 대비 미판매 상품 AI 추천
- 판가 설정 + DM 발송 실행
- 발송 후 실적(매출·GP) 추적

## 👥 권한 구조

| 구분 | 조회 범위 | 해당자 |
|------|-----------|--------|
| **일반 영업사원** | 본인 담당 거래처만 | 전체 영업사원 |
| **팀장/지점장** | 담당 팀·지점 전체 | 외식1팀·2팀·3팀·영남지점 팀장 |
| **신규개발파트** | 외식식재사업부 전체 (읽기 전용) | 신규개발파트 소속 |

> 챗봇도 동일한 권한 구조가 적용됩니다.  
> 신규개발파트는 플랫폼에서 전체 가맹점 데이터 조회가 가능하나 DM 발송 등 액션은 본인 담당 거래처만 가능합니다.
