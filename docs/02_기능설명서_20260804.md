## 1. 서비스 개요

### 배경
동원홈푸드 외식식재사업부의 가맹점별 범용상품(전용상품 외 상품) 판매 비중은 가맹점마다 편차가 큽니다.  
이 편차를 데이터로 식별하고, 타 가맹점 대비 미판매 상품을 추천하여 영업사원이 빠르게 액션할 수 있도록 지원합니다.

### 데이터 원천
- **SAP / Databricks**: 매출, GP, 매출수량, 거래처, 자재, 대금청구일 등 전사 데이터
- **자재 분류**: `자재그룹명 = FC전용상품` → 전용상품, 그 외 자재그룹 있는 상품 → 범용상품
- **가맹점 분류**: ZC코드 8로 시작 → 가맹점, 그 외 → 일반외식업장
- **데이터 갱신**: Databricks Delta 테이블 기준 (일 배치 적재)

### 2-1. 로그인 및 대시보드

#### 대시보드 (`/portal`)
| 항목 | 설명 |
|------|------|
| **매출액** | 현월 담당 거래처 전체 매출 합계 |
| **담당 브랜드** | ZC코드 기준 가맹 브랜드 수 |
| **가맹점** | ZC코드 8 시작 거래처 수 |
| **일반외식업장** | ZC코드 외 거래처 수 |

| **공헌이익률** | (매출 - 매출원가) / 매출 |

### 2-2. 범용상품 제안 솔루션 — 분포 분석 (`/portal/brand-report`)

#### 목적
브랜드별 가맹점의 범용상품 구성비 분포를 파악하고, 구성비가 낮은 가맹점(제안 대상)을 식별합니다.

#### 화면 구성

**① 브랜드 선택**
- 담당 브랜드 중 분석할 브랜드 선택
- 일반외식업장 포함 선택 가능

**② 분포 차트**
- 전체 가맹점 범용 구성비 분포 막대 그래프
- 브랜드 평균선 표시
- 제안 임계값 슬라이더로 대상 설정 (기본: 브랜드 평균)

**③ 거래처 목록 (전체)**
| 컬럼 | 설명 |
|------|------|
| 거래처명 | 가맹점 상호 |
| 매출(백만) | 선택월 매출 |
| 전용상품(백만) | FC전용상품 매출 |
| 범용상품(백만) | 범용상품 매출 |
| 범용 구성비(%) | 범용 / (전용+범용) × 100 |
| 브랜드 GAP | 브랜드 평균 대비 차이 |
| 제안 대상 | 임계값 미달 시 🎯 표시 |

**④ 제안 대상 목록**
- 범용 구성비 < 임계값인 가맹점만 필터
- 필요 추가 매출 계산: `(목표구성비 × 분류매출 - 현재범용매출) / (1 - 목표구성비)`

**⑤ 예상 KPI**
- 제안 가능 추가 매출 합계 (백만원)
- 예상 수익 증가 (GP율 적용)

> **조회 기준**: 최신 데이터월 기준 전월/당월 선택 가능

### 2-3. 범용상품 제안 솔루션 — 액션 실행 (`/portal/brand-report/action`)

#### 목적
분포 분석에서 선택한 가맹점에 대해 **추천 상품을 확인하고 DM 발송 또는 판가 설정**을 실행합니다.

#### 액션 실행 흐름

```
분포 분석 화면에서 가맹점 선택
        ↓
추천 상품 목록 확인 (최대 30개)
        ↓
DM 발송 품목 선택 (체크박스)
        ↓
판가 설정 (SAP 전송 또는 DM 전용)
        ↓
DM 발송 실행 (카카오톡 메시지)
        ↓
결과 기록 → T_ACTION_RESULTS 집계
```

#### 추천 상품 로직
- **대상**: 같은 브랜드의 다른 가맹점이 최근 3개월 내 구매했으나, **이 가맹점은 최근 3개월 내 미구매**인 상품
- **정렬**: 구매 가맹점 수 ↓, GP율 ↓, 매출 ↓
- **제외**: FC전용상품, 자재그룹명 없는 상품

#### 판가 설정 패널
| 항목 | 설명 |
|------|------|
| 자재코드 | 발송할 상품의 SAP 자재코드 |
| 자재명 | 자동 조회 |
| 설정 판가 | 영업사원이 입력 (원 단위) |
| 원가 | T_MAIN 기준 평균 원가 자동 입력 (읽기 전용) |

- **품목 확정** 버튼 클릭 후 발송 버튼 활성화
- 자재코드가 없으면 발송 버튼 비활성화
- 발송 전 confirm 팝업 표시

#### DM 발송 유형
| 발송 유형 | 설명 |
|-----------|------|
| SAP 판가전송 + DM 발송 | SAP에 판가 저장 후 카카오 DM 발송 |
| DM만 발송 | 판가 저장 없이 DM만 발송 |
| 판가설정만 | DM 없이 SAP 판가만 저장 |

> 현재 DM 발송은 **기록 모드** (실제 카카오 발송 준비 중)

### 2-4. 액션 실적 조회 (`/portal/brand-report/results`)

#### 목적
DM 발송·판가 설정 이후 해당 가맹점의 매출·GP 실적 변화를 추적합니다.

#### 실적 집계 기준
- **기준일**: 액션 실행일 (`action_date`) 이후 대금청구일 기준
- **대상 자재**: DM 발송 시 선택한 자재코드만 집계 (`ARRAY_CONTAINS` 필터)
- **갱신**: 🔄 실적 리프레시 버튼 클릭 시 Databricks 재집계

#### 목록 컬럼
| 컬럼 | 설명 |
|------|------|
| 가맹점명 / 코드 | 가맹점 기본 정보 |
| 브랜드 | ZC본부명 |
| 액션월 | 최초 액션 실행월 (YYYYMM) |
| 설정품목 | 판가 설정 자재 수 |
| DM발송 | 발송 횟수 |
| 판가설정 | 설정 횟수 |
| DM발송품목 | 📌 상세 버튼 → 자재별 상세 테이블 펼침 |
| 이후누적매출 | 액션일 이후 DM 발송 자재 매출 합계 (백만) |
| 이후GP | 액션일 이후 GP (백만) |
| GP율 | GP / 매출 × 100 |
| 범용추가 | 범용상품 추가 매출 (백만) |
| 샘플출고 | 샘플(매출=0, 수량>0) 건수 |
| DM전환(건) | DM 발송 자재 중 실제 매출 발생 자재 종류 수 |

#### 자재별 상세 테이블 (📌 상세 클릭)
| 컬럼 | 설명 |
|------|------|
| 자재코드 | SAP 자재코드 |
| 자재명 | 자재 품목명 |
| 설정판가 | `예판 ₩X` (SAP 판가전송 기록 있음) / `기존 ₩X` (평균단가) |
| 발송후 매출 | 액션일 이후 해당 자재 매출 (백만) |
| 발송후 GP | 해당 자재 GP (백만) |
| GP율 | GP% (20%↑ 녹색 / 10~20% 노랑 / 미만 빨강) |
| 매출수량 | 매출 발생 수량 |
| 샘플 | 샘플 출고 수량 |
| 전환 | ✅ (매출 발생) / - (미발생) |

> 실적 없는 자재도 목록에 표시됨 (행 투명도 낮게 표시)

#### 필터
- 브랜드별 필터 (전체 또는 특정 브랜드)
- 액션월 기준 이후 필터 (YYYYMM 직접 입력)

### 2-6. 관리자 기능 (`/portal/admin`)

> 지정된 관리자 계정만 접근 가능

#### 사용자 관리 (`/portal/admin/users`)

- **활성/비활성 토글**: 비활성 공지는 사용자에게 미표시
- **삭제**: 공지 영구 삭제

> 공지 등록 즉시 모든 사용자의 대시보드 카드 및 팝업에 반영됩니다.

## 3. AI 영업지원 챗봇 (카카오톡)

### 접속 방법
1. 카카오톡 → `동원홈푸드 영업지원` 채널 검색
2. 채널 추가 후 사번 입력 → 인증 후 이용

### 주요 기능
| 기능 | 질문 예시 |
|------|-----------|
| 거래처 매출 조회 | "이번 달 신화푸드 매출 얼마야?" |
| 거래처 미수채권 | "193241 미수채권 확인해줘" |
| 브랜드별 현황 | "내 담당 가맹점 중 어디가 제일 매출 높아?" |
| 범용상품 현황 | "스파이더킹 범용 비중 낮은 가맹점 알려줘" |
| 추천 상품 조회 | "193241에 추천할 상품 있어?" |

### 조회 범위
- 챗봇도 플랫폼과 동일한 권한 구조 적용
- 일반 영업사원: 본인 담당 거래처만 조회
- 신규개발파트: 전체 사업부 조회 가능

### 주의사항
- 실시간 SAP 연동이 아닌 Databricks Delta 테이블 기준 (일 배치)
- 조회 결과 최신화 시점: 전일 데이터 기준

## 4. 권한 구조 상세

```
관리자 (1인)
├── 전체 사업부 데이터 조회
├── 사용자 관리, 공지 등록
└── DM 발송, 판가 설정 (본인 담당 거래처)

신규개발파트 (readonly_all)
├── 전체 사업부 데이터 조회 (읽기 전용)
└── DM/판가는 본인 담당 거래처만 가능

팀장/지점장 (team_leader)
├── 담당 팀·지점 전체 데이터 조회
│   ├── 외식1팀장: 외식1팀 전체
│   ├── 외식2팀장: 외식2팀 전체
│   ├── 외식3팀장: 외식3팀 전체
│   └── 영남지점장: 영남지점 전체
└── DM 발송, 판가 설정 (본인 담당 거래처)

일반 영업사원 (user)
├── 본인 영업사원코드 기준 거래처만 조회
└── DM 발송, 판가 설정 (본인 담당 거래처)
```

## 5. 데이터 기준 및 용어 정의

### 자재 분류
| 분류 | 기준 | 설명 |
|------|------|------|
| **FC전용상품** | `자재그룹명 = 'FC전용상품'` | 해당 브랜드 전용 납품 상품 |
| **범용상품** | `자재그룹명 IS NOT NULL AND ≠ 'FC전용상품'` | 여러 채널에서 공용 판매 가능 상품 |
| **분류 불가** | `자재그룹명 IS NULL` | 집계에서 제외 |

### 매출 관련
| 용어 | 기준 |
|------|------|
| **매출액** | SAP 청구기준 매출 (단위: 원, 내부 단위 × 100 = 원) |
| **매출원가** | SAP 기준 매출원가 |
| **GP** | 매출액 - 매출원가 |
| **GP율** | GP / 매출액 × 100 (%) |
| **백만원 단위** | 원 단위 ÷ 10,000 = 백만원 |

### 샘플 기준
- `매출액 = 0 AND 매출수량 > 0` → 샘플 출고로 분류

### 기간 기준
| 화면 | 기준 |
|------|------|
| 대시보드 | 최신 데이터월 (전월/당월 선택 가능) |
| 분포 분석 | 최신월 기준 (전월/당월 선택 가능) |
| 추천 상품 | 최신 데이터 기준 최근 3개월 |
| 액션 실적 | 액션 실행일(`action_date`) 이후 전체 |

## 6. 자주 묻는 질문 (FAQ)

**Q. 대시보드의 데이터가 실시간인가요?**  
A. 아닙니다. Databricks Delta 테이블 기반으로 보통 전일 데이터가 최신입니다. 화면 우측 상단에서 최신 데이터 기준월을 확인할 수 있습니다.

**Q. 추천 상품에 이미 사용 중인 상품이 뜨는 경우가 있어요.**  
A. 추천 로직은 최근 3개월 기준으로 미구매 여부를 판단합니다. 4개월 이전에 마지막으로 구매한 상품은 다시 추천될 수 있습니다.

**Q. DM 발송 후 실적에 반영이 안 돼요.**  
A. 🔄 실적 리프레시 버튼을 클릭하면 Databricks에서 최신 데이터로 재집계됩니다. 데이터 적재 시점(전일)에 따라 당일 매출은 다음날 반영됩니다.

**Q. 판가 설정이 SAP에 실제로 반영되나요?**  
A. `SAP 판가전송 + DM 발송` 선택 시 SAP API 연동을 통해 저장 시도합니다. 성공/실패 여부는 발송 후 결과 메시지에서 확인하세요. 현재 테스트 환경에서 운영 중입니다.

**Q. 비밀번호를 잊어버렸어요.**  
A. 관리자에게 문의하면 임시 비밀번호(사번 뒤 4자리)로 초기화해드립니다.

**Q. 팀원 전체 데이터를 보고 싶은데 본인 것만 보여요.**  
A. 팀장/지점장 권한이 부여된 계정만 팀 전체 조회가 가능합니다. 권한 조정이 필요하면 관리자에게 문의하세요.

**Q. 모바일에서도 사용 가능한가요?**  
A. 플랫폼은 반응형으로 모바일 브라우저에서도 이용 가능합니다. 단, 넓은 테이블이 많아 태블릿 이상 환경을 권장합니다.

**Q. VOC 게시판에 올린 내용을 수정할 수 있나요?**  
A. 현재 수정 기능은 없습니다. 삭제 후 재작성해주세요. (수정 기능은 추후 추가 예정)
